# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, keep criticism about the code and not the person, and help newcomers.

If someone's behaviour in this project's issues, pull requests or other spaces makes you uncomfortable, report it privately through **Security → Report a vulnerability** on this repository (it reaches only the maintainer) and say it's a conduct report. Reports are kept confidential.
